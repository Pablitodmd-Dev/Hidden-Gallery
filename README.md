## 📄 Project Overview
**Hidden Gallery** is a minimalist and relaxing puzzle experience designed for the web. The player takes on the role of a restorer discovering an abandoned, secret collection. The goal is to reconstruct fragmented works of art to reveal the beauty hidden beneath the damage. No timers, no scores—just the quiet satisfaction of bringing art back to life.

### Design Pillars
* **Zen Calm:** No fail states. The game is a meditative space focused on the process, not just the result.
* **Tactile Satisfaction:** Fluid piece movement and a rewarding "magnetic snap" when a piece finds its home.
* **Aesthetic Reward:** Every completed puzzle reveals a high-quality artwork, making the gallery feel "alive" again.

---

## 🎨 Key Features

* **🧩 Core Puzzle Gameplay:** Drag, drop, and rotate. Once a piece is correctly placed and oriented, it locks into the canvas.
* **🔄 Manual Rotation:** To keep the puzzle engaging, pieces start at random 90° angles and must be rotated by the player.
* **✨ ASMR Feedback:** High-quality sound design featuring canvas friction, soft wooden clicks, and subtle visual sparkles upon completion.
* **🏛️ The Secret Archive:** A main menu that acts as a growing exhibition. Each restored piece is framed and permanently displayed on the gallery walls.

## 🕹️ Game Structure

The game is organized into **Discovery Wings**. Each wing contains 3 to 5 themed paintings (e.g., The Renaissance Wing, The Sketch Room).

| Phase | Action | Description |
| :--- | :--- | :--- |
| **Selection** | Explore Wing | The player chooses a dusty, blank frame from the gallery wall. |
| **Restoration** | Rebuild Canvas | Fragmented and rotated pieces are laid out on the workspace to be assembled. |
| **Completion** | Reveal Art | The painting is fully restored, lines disappear, and it takes its place in the gallery. |

### Progressive Complexity
Difficulty scales gently through:
1.  **Piece Count:** Starting with simple 2x2 or 3x3 grids for beginners, moving up to 25+ fragments.
2.  **Visual Detail:** Transitioning from bold, high-contrast images to subtle, monochromatic sketches that challenge observation.

## 🎮 Controls

Optimized for web browsers and intuitive mouse/touch interaction.

| Action | Input |
| :--- | :--- |
| **Select / Drag Piece** | `Left Click (Hold)` |
| **Rotate Piece** | `Right Click` or `R` (while holding/dragging) |
| **Zoom In/Out** | `Mouse Wheel` |
| **Menu / Back** | `Esc` |
